# Markdown 入门指南

> 面向完全没接触过 Markdown 的新人。学完这一篇，你就能读懂并书写本项目中的文档和帖子。
> 本仓库中几乎所有文字内容都是用 Markdown 写的：`README.md`、`docs/` 下的文档、`public/posts/` 下的帖子正文。

## 一、Markdown 是什么？

Markdown 是一种**轻量级标记语言**：用简单符号(如 `#`、`*`、`-`)标记文字的含义，写起来像普通纯文本，渲染出来却是排版好的文档(标题、列表、加粗……)。

- 编写简单，一个普通文本编辑器就能写；
- 源码可读性强，也方便在 Git 里对比改动；
- GitHub 会自动渲染 `.md` 文件，在网页上直接看到排版效果。

推荐Markdown专用渲染编辑器: [**marktext**](https://marktext.me/)

当然你可以直接使用 vscode 或者 jetbrain IDE 等会自动渲染markdown的IDE

## 二、标题

用 `#` 表示标题，`#` 越多级别越低(最多六级)。`#` 后面记得加一个空格。

```markdown
# 一级标题(H1，一个文件建议只用一个)
## 二级标题
### 三级标题
#### 四级标题
```

本项目示例(`docs/TODO.md`)：

```markdown
# TODO LIST

- [ ] 整理现有的仓库代码
```

## 三、段落与换行

- 两个段落之间用**空行**分隔；
- 段落内部想强制换行，在行尾加两个空格再回车；
- 最省心的做法：每句话/每段之间都留空行。

```markdown
这是第一段。

这是第二段。
```

## 四、强调(粗体、斜体、删除线)

```markdown
**这是粗体**      用两个 * 或两个 _ 包裹
*这是斜体*        用一个 * 或一个 _ 包裹
***粗斜体***      三个组合
~~这是删除线~~    两个波浪线包裹
```

本项目示例(`docs/PLAN.md`)：

```markdown
> 这个阶段有点像那种学校官网， 只分享， 不互动
```

## 五、列表

### 无序列表

用 `-`、`*` 或 `+` 开头：

```markdown
- 苹果
- 香蕉
- 橙子
```

### 有序列表

用 `1.` `2.` `3.` 开头(数字自动排序，写错了也会按顺序渲染)：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 嵌套列表

子项缩进两个空格：

```markdown
- 前端
  - 页面
  - 组件
- 后端
```

### 任务列表(勾选框)

用 `- [ ]` 表示未完成，`- [x]` 表示已完成。本项目 `docs/TODO.md` 就在用：

```markdown
- [x] 整理现有的仓库代码
- [ ] 确定后端需要实现的内容以及预留的接口
```

## 六、链接与图片

```markdown
[链接文字](https://github.com/Guidezzyz/guide-zzyz-web)

![图片替代文字](图片地址)
```

- 图片和链接的写法几乎一样，区别是图片前面多一个 `!`；
- 替代文字(alt)在图片加载失败时显示，建议写上；
- 指向**仓库内其他文件**用相对路径，例如 `[贡献指南](/docs/CONTRIBUTION.md)`；
- 指向外部的链接写完整地址，例如 `[阿里云短信文档](https://help.aliyun.com/zh/sms/developer-reference/sdk-product-overview/)`(本项目 `docs/PLAN.md` 中的写法)。

## 七、引用(Blockquote)

用 `>` 开头，表示引用别人或强调一段话：

```markdown
> 这是一段引用文字。
> 第二行引用。
```

## 八、代码

### 行内代码

用反引号 `` ` `` 包裹，用于提到命令、文件名等：

```markdown
运行 `npm run dev` 启动开发服务器。
```

### 代码块

用三个反引号包裹，可指定语言获得高亮：

````markdown
```bash
npm run dev
```

```tsx
export default function App() { ... }
```
````

## 九、分割线

三个及以上的 `-`、`*` 或 `_` 单独成行：

```markdown
---
```

## 十、表格

```markdown
| 列名 1 | 列名 2 |
| ------ | ------ |
| 内容 a | 内容 b |
```

表头用 `|` 分隔，第二行是分隔线，下面的行是数据。

## 十一、YAML front matter(元信息)

在 `.md` 文件**最开头**，用 `---` 包裹一段 `键: 值` 的元信息，用来描述标题、作者、日期等。本项目帖子正文就在用(`public/posts/post1.md`)：

```yaml
---
title: "指南酱"
author: "老秦"
date: "2026-02-21"
---
```

- 键和值之间要有一个空格；
- 日期等建议加引号；
- 代码渲染时这段不会被显示为正文，而是作为文档的属性。

## 十二、其他常用技巧

- **转义**：想显示 `#`、`*` 等特殊字符本身，在它前面加反斜杠，如 `\#`、`\*`；
- **目录**：部分平台支持在文中写 `[TOC]` 自动生成目录(本项目帖子中有使用)；
- **HTML**：Markdown 里可以直接写 HTML 标签，GitHub 会原样渲染(进阶用法，新手少用)。

## 十三、练习建议

1. 打开 `docs/utils/markdown.md`，对照本文看每种语法对应的渲染效果；
2. 用任意编辑器(VS Code、Typora、甚至是 GitHub 网页)新建一个 `.md` 文件，把本文的语法各写一遍；
3. 在 GitHub 仓库页面可以直接点击文件查看渲染后的效果，写完文档后记得检查一遍排版；
4. 写完后提交(`git add` + `git commit` + `git push`)，流程见 [Git 入门指南](/docs/utils/git.md)。

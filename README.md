
# Guide-zzyz

## What is Guide-zzyz

这是一个由 zzyz 的毕业生发起的项目
该网页主要通过标签化的文档收录与呈现为 zzyz 的学生提供一些关于学习上的,大学上的,生活上的信息和建议
由团队成员在课余时间自愿推进
是一群大学生为爱发电的证明

## Why Guide-zzyz

很多高中学生学业压力繁重, 对未来感到迷茫, 学习上也经常遇到一些无法独立解决的瓶颈
而我们团队的成员自己也经历过这些, 我们提前踩坑和试错, 对于这些问题产生了自己的理解
而且对于大学生活我们再熟悉不过, 我们希望高中生在迷茫的时候点开这个网站, 可以看到一点 真诚, 热情, 温柔.
你们走过的路, 我们也走过, 所以我们希望提供力所能及的帮助, 就是这样
